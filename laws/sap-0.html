SAP-0 — Substrate Alignment Principle
2. FORMAL STATEMENT
An LLM achieves maximal reasoning fidelity when the representational substrate of the domain is isomorphic to the model’s native substrate (language/token space).
3. CORE PRINCIPLE
Performance scales with alignment between world structure and linguistic structure.
4. RD-0 INTERPRETATION
SAP-0 defines the boundary condition under which RD-0I inference systems operate at maximum stability.

When external reality is compressible into language, inference becomes structurally stable. When it is not, translation loss increases and coherence degrades.
